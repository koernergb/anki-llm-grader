# Anki LLM Grader

An Anki add-on that will grade typed answers with an LLM. The current M0
milestone provides the add-on skeleton and confirms that its reviewer assets
load successfully.

## M0 installation

1. In Anki, open **Tools → Add-ons → View Files**.
2. Copy or symlink `add_on/anki_llm_grader` into the displayed `addons21`
   directory.
3. Restart Anki and begin reviewing a card.
4. Confirm that **LLM Grader loaded** appears at the lower-right of the
   reviewer.

M0 does not grade cards yet. Typed-answer capture and the grading button are
planned for M1.
