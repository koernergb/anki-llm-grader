Thought for 31s
You can do “LLM grading only” as an Anki add-on by:

injecting a little JavaScript into the reviewer webview to read the typed answer box, and

sending it back to Python via pycmd(...), then

calling your LLM, and

showing the result back in the reviewer UI.

Anki explicitly supports this pattern: you can modify reviewer HTML/JS with gui_hooks.webview_will_set_content() and intercept JS messages with gui_hooks.webview_did_receive_js_message(), using the pycmd(string) bridge. 

Below is a realistic “minimal” blueprint.

Minimal add-on design
What you’ll build
A hotkey or button: “Grade with AI”

Works on cards that use {{type:...}} (typed answer cards)

When clicked:

JS grabs the typed input text

sends pycmd("llmgrade:...")

Python receives it, calls LLM, returns verdict + missing points

JS renders a small panel in the reviewer

Add-on skeleton (files)
Create a new add-on folder (Tools → Add-ons → View Files → create folder anki_llm_grader/):

anki_llm_grader/
  __init__.py
  web/
    grader.js
    grader.css
Then register web exports so Anki can serve your JS/CSS from /_addons/... (Anki supports this). 

Core hook points you’ll use
1) Inject JS/CSS into the reviewer webview
Use gui_hooks.webview_will_set_content() to append your assets. 

2) Receive messages from JS in Python
Use gui_hooks.webview_did_receive_js_message() to intercept pycmd(...) messages. 

Minimal code (conceptual but close-to-real)
__init__.py (Python side)
from __future__ import annotations

import json
import urllib.parse
from dataclasses import dataclass
from typing import Optional

import requests
from aqt import mw, gui_hooks
from aqt.webview import WebContent

ADDON_CMD_PREFIX = "llmgrade:"


def _addon_package() -> str:
    return mw.addonManager.addonFromModule(__name__)


def on_webview_will_set_content(web_content: WebContent, context) -> None:
    # Only inject into reviewer
    # context varies by screen; reviewer typically has a "reviewer" attr or name
    if not getattr(context, "reviewer", None):
        return

    pkg = _addon_package()
    web_content.js.append(f"/_addons/{pkg}/web/grader.js")
    web_content.css.append(f"/_addons/{pkg}/web/grader.css")


def on_js_message(handled: bool, message: str, context) -> tuple[bool, Optional[str]]:
    # Let other handlers run if not ours
    if not isinstance(message, str) or not message.startswith(ADDON_CMD_PREFIX):
        return handled, None

    # Only handle in reviewer context
    reviewer = getattr(context, "reviewer", None)
    if reviewer is None:
        return True, None

    payload_enc = message[len(ADDON_CMD_PREFIX):]
    payload_json = urllib.parse.unquote(payload_enc)
    payload = json.loads(payload_json)

    user_answer = payload.get("userAnswer", "")
    correct_answer = payload.get("correctAnswer", "")
    prompt_text = payload.get("prompt", "")

    result = grade_with_llm(prompt_text, correct_answer, user_answer)

    # Send result back into webview (call a JS function we define)
    reviewer.web.eval(f"window.__llmGradeShowResult({json.dumps(result)});")

    return True, None


def grade_with_llm(prompt: str, correct: str, user: str) -> dict:
    """
    Replace this with your provider.
    Keep it deterministic: low temp, JSON output.
    """
    # Example: call a local server you run (recommended),
    # so you don't store API keys in the addon.
    resp = requests.post(
        "http://127.0.0.1:8787/grade",
        json={"prompt": prompt, "correct": correct, "user": user},
        timeout=20,
    )
    resp.raise_for_status()
    return resp.json()


def init():
    # Expose web assets
    mw.addonManager.setWebExports(__name__, r"web/.*(css|js)")

    gui_hooks.webview_will_set_content.append(on_webview_will_set_content)
    gui_hooks.webview_did_receive_js_message.append(on_js_message)


init()
Why this is the “right shape”:

It uses the supported webview injection + JS message bridge. 

It avoids fighting Anki internals to “find” typed answer state in Python; you just read it from DOM where it exists.

web/grader.js (JS side)
(function () {
  function getTypeAnswerInput() {
    // The typed answer box is usually an <input> or <textarea>.
    // You may need to inspect the DOM in Anki's reviewer to confirm selectors.
    return document.querySelector("input[type='text'], textarea");
  }

  function getPromptText() {
    // You can grab the visible question text from the DOM.
    // Often #qa contains the card HTML.
    const qa = document.querySelector("#qa");
    return qa ? qa.innerText.trim() : "";
  }

  function getCorrectAnswerText() {
    // If you're on the answer side, the correct answer is visible.
    // Minimal approach: just capture all text; better is to use a dedicated field marker.
    const qa = document.querySelector("#qa");
    return qa ? qa.innerText.trim() : "";
  }

  function ensurePanel() {
    let el = document.querySelector("#llm-grade-panel");
    if (!el) {
      el = document.createElement("div");
      el.id = "llm-grade-panel";
      el.innerHTML = `
        <div class="llm-grade-header">
          <button id="llm-grade-btn">Grade with AI</button>
          <span id="llm-grade-status"></span>
        </div>
        <div id="llm-grade-output"></div>
      `;
      document.body.appendChild(el);

      document.querySelector("#llm-grade-btn").addEventListener("click", () => {
        const inp = getTypeAnswerInput();
        const userAnswer = inp ? inp.value : "";
        const payload = {
          userAnswer,
          prompt: getPromptText(),
          correctAnswer: getCorrectAnswerText(),
        };
        const enc = encodeURIComponent(JSON.stringify(payload));
        document.querySelector("#llm-grade-status").textContent = "Grading…";
        // pycmd() is provided by Anki in reviewer webviews. :contentReference[oaicite:5]{index=5}
        pycmd("llmgrade:" + enc);
      });
    }
    return el;
  }

  window.__llmGradeShowResult = function (result) {
    ensurePanel();
    document.querySelector("#llm-grade-status").textContent = "";
    const out = document.querySelector("#llm-grade-output");
    const missing = (result.missing_points || []).map(x => `<li>${escapeHtml(x)}</li>`).join("");
    out.innerHTML = `
      <div><b>${escapeHtml(result.verdict || "unknown")}</b> (score: ${result.score ?? "?"})</div>
      ${result.feedback_short ? `<div>${escapeHtml(result.feedback_short)}</div>` : ""}
      ${missing ? `<div>Missing:</div><ul>${missing}</ul>` : ""}
    `;
  };

  function escapeHtml(s) {
    return String(s).replace(/[&<>"']/g, (c) => ({
      "&": "&amp;", "<": "&lt;", ">": "&gt;", '"': "&quot;", "'": "&#039;"
    }[c]));
  }

  // Anki re-renders content; re-create UI often.
  // Cheap approach: try every time DOM changes.
  const obs = new MutationObserver(() => ensurePanel());
  obs.observe(document.documentElement, { childList: true, subtree: true });

  ensurePanel();
})();

How to make grading actually good (minimal rubric)
Your grading server (the POST /grade endpoint) should return a strict JSON like:

{
  "verdict": "correct|partial|incorrect",
  "score": 0.0,
  "missing_points": ["..."],
  "feedback_short": "..."
}
Keep temperature low. Make the model check required points.

The one tricky bit: finding the “correct answer”
For typed-answer cards, Anki’s “correct answer” is typically a specific field, not the entire back side.

Two robust options:

Add a dedicated field like AnswerKey and include it invisibly in the template inside a hidden span with an id, then your JS reads that exact element.

Use a template marker like:

<span id="llm_answer_key" style="display:none">{{AnswerKey}}</span>
Then document.querySelector("#llm_answer_key").innerText.

This avoids accidentally sending the whole back side or extra explanation text.
